Why is Windows Update failing or stuck?

An update that fails again and again is usually telling you about something else: not enough free space, damaged update files or an unstable connection.

Get it diagnosedAsk on WhatsApp
In short

Windows Update usually fails for one of four reasons: too little free space on the drive, damaged update files, an unstable or metered internet connection, or a driver the update cannot work with. Free at least 20GB, run the Windows Update troubleshooter, then run the two repair commands below. Never switch the computer off while it says it is working on updates.

Self-checks

What you can check yourself

These are safe to try, cost nothing and do not need tools.

  1. Restart and try once more

    Restart the computer, then open Settings, Windows Update and choose Check for updates.

  2. Check the date and time

    A wrong date or time stops Windows from trusting the update servers. Set it to automatic in Settings, Time & language.

  3. Free up space

    Large updates need room to unpack. Free at least 20GB in Settings, System, Storage.

  4. Check your data

    Updates are large, often several gigabytes. On prepaid mobile data, make sure there is enough, and check that the connection is not set as metered, which pauses downloads.

  5. Run the troubleshooter

    Windows 11: Settings, System, Troubleshoot, Other troubleshooters, Windows Update. Windows 10: Settings, Update & Security, Troubleshoot, Additional troubleshooters.

  6. Unplug what you do not need

    Remove USB drives, printers and other accessories before installing a large update.

  7. Repair the update files

    Right-click the Start button and open Terminal (Admin) or Command Prompt (Admin). Run these one after the other, waiting for each to finish:

    DISM /Online /Cleanup-Image /RestoreHealthsfc /scannow

  8. Read the update history

    Settings, Windows Update, Update history shows which update failed and the error code. Keep the code: it speeds up a diagnosis.

Stop and get it looked at if
  • The computer restarts in a loop and never reaches the desktop.
  • The same error code returns after all the checks.
  • Windows has become unstable since the failed update.

Do not switch the computer off while it says “Working on updates”. Interrupting an update is one of the ways Windows gets damaged.

Questions

Common questions

Can I just turn Windows updates off?

You can pause them for a few weeks, but leaving them off leaves known security holes open. It is better to fix the reason they fail.

My PC still runs Windows 10. Does it still get updates?

Standard support for Windows 10 ended on 14 October 2025. Microsoft offers Extended Security Updates for eligible home PCs until 12 October 2027. See what to do about Windows 10.

Will I lose my files if the update is repaired?

A repair keeps your files and programs. If a reinstall turns out to be necessary, backing up comes first and is agreed with you before anything is erased.
