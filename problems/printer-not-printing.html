Fault F-09Printers

Why will my printer not print?

Most printing faults are connection or software faults, not a broken printer. The printer and the computer have stopped talking to each other.

Get it diagnosedAsk on WhatsApp
In short

A printer that will not print is usually offline (the computer cannot reach it), blocked by a stuck job in the print queue, or using a driver that an update has broken. Check that the printer is on the same Wi-Fi network as the computer, clear the print queue, and restart the Print Spooler service. If a new router was installed, the printer still has the old Wi-Fi details and must be reconnected.

Self-checks

What you can check yourself

These are safe to try, cost nothing and do not need tools.

  1. Restart the printer and read its panel

    Switch it off and on. Look for a warning light or a message about paper, ink or a jam.

  2. Check both are on the same network

    Print the network report from the printer's own menu. The Wi-Fi name on it must match the one the computer is using.

  3. Check it is not set to offline

    Settings, Bluetooth & devices, Printers & scanners. Open the printer, open the print queue, and in the Printer menu make sure Use Printer Offline is not ticked.

  4. Clear the queue

    In the print queue, cancel every document.

  5. Restart the Print Spooler

    Press the Windows key, type services and open it. Find Print Spooler, right-click it and choose Restart.

  6. Remove the printer and add it again

    Remove it in Printers & scanners, then add it again. Install the driver from the printer maker's support page for your exact model.

  7. Try a USB cable

    If it prints over USB but not over Wi-Fi, the printer is fine and the network is the problem.

It is a printer repair, not a setup problem, if
  • The printer makes grinding noises or jams on every page.
  • It shows a hardware error code that returns after a restart.

Questions

Common questions

Why does my printer keep going offline?

Usually because the router gives it a different address each time it reconnects, or because the printer drops off the Wi-Fi when it sleeps. Giving the printer a fixed address in the router normally stops it.

Can several computers share one printer?

Yes. A printer on the office network can be added to every computer and phone that needs it. That is part of a normal office setup.

Can you fix a printer remotely?

Driver, queue and sharing problems, often yes. Anything that needs the printer's own panel or a cable needs someone in the room.
