Display & startup help

Why is my laptop screen black
but the power is on?

A black screen is different from a blue-screen stop error. The device may be running while Windows, the display path or the boot process is failing.

Common causes

Display driver faults, a frozen Windows process, incorrect display output, incomplete updates, startup corruption, display cable/panel issues and boot-device problems can all create a black screen.

Useful clues

Note whether you see a cursor, hear Windows sounds, can connect an external screen, or whether the problem began after an update or drop. These details help separate display problems from startup problems.

When to request diagnosis

If the screen stays black after basic restart checks, the device has been dropped, an external display also fails, or the machine cannot reach Windows, a proper diagnostic is safer than repeated forced restarts.
